### Step Instructions

Ballast is a weight used to shift the CG. There are two types of ballasts employed on an aircraft: temporary and permanent ballasts. When a temporary ballast is used, determining "how much weight is needed to place on the aircraft?" can be calculated using this formula:

Ballast weight = (total acft weight x the distance needed to shift CG) / (distance between ballast location and desired CG)

1. Identify the aircraft total weight1.
2. Identify how far CG is out of range2.
3. Identify ballast location3.
4. Determine temporary ballast weight4.

### Senior Mechanic Notes

1. This is often a given value to use (e.g., ACFT weight 2,500 LBS).
2. A range will be given for CG and the current CG location (e.g., 64"-70"; CG @ 71.2"). Subtract the desired location from the current location (e.g., 71.2" - 70" = 1.2"), this is how far out of range the CG is. When shifting CG, shift it to the closest limit it currently is out of.
3. This location is usually a baggage compartment or a given fuselage station (e.g., ballast location +45").
4. Plug the values into the formula for the needed ballast weight. Using the previous example calculations: (2,500 x 1.2) / (70-45) = 3,000 / 25 = 120 LBS.
